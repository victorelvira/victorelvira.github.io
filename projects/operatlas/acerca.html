About Operatlas

An interactive opera database — maps, timeline, connections and curiosities.

Operatlas is a personal, non-commercial project. It gathers data from several open sources and cross-references and validates them against each other: every opera is linked to its composer, librettist, literary source, premiere, characters and duration, and those connections can be explored freely.

Data sources

Wikidata CC0 · public domain

Composers, librettists, premiere dates and venues, literary sources and coordinates. The metadata backbone of the project. wikidata.org

Wikipedia CC BY-SA

A synopsis for each opera (lead paragraph). Every opera links back to the original article as attribution. wikipedia.org

MusicBrainz CC0 · public domain

Per-act durations from recordings (net musical duration). musicbrainz.org

The Opera 101 reference

Staged running times, used as a validation reference against the recording durations. theopera101.com

How they are cross-referenced

There is no shared identifier across sources, so matching is done by composer + title (resolving titles across several languages), with common-sense checks — for example, a premiere dated after the composer's death is discarded. Figures are approximate and improve over time.
