About Operatlas

An interactive opera database — maps, timeline, connections and curiosities.

Operatlas is a personal, non-commercial project. It gathers data from several open sources and cross-references and validates them against each other: every opera is linked to its composer, librettist, literary source, premiere, characters and duration, and those connections can be explored freely.

Data sources

Wikidata CC0 · public domain

Composers, librettists, premiere dates and venues, literary sources and coordinates, plus the category (opera seria / buffa / verismo…) from the genre. The metadata backbone. wikidata.org

Wikipedia CC BY-SA

A synopsis for each opera, and the characters and their voice types read from the Roles table. Every opera links back to the original article as attribution. wikipedia.org

MusicBrainz CC0 · public domain

Per-act durations from recordings (median across many, with the spread shown), and the ordered musical numbers from the work tree. musicbrainz.org

How they are cross-referenced

There is no shared identifier across sources, so matching is done by composer + title (resolving titles across several languages), with common-sense checks — for example, a premiere dated after the composer's death is discarded. Figures are approximate and improve over time.

A note on the music itself

The categories, voice types and musical-number forms come from text (genres, role tables, number titles), not from reading the scores. A true note-by-note map of key and tempo would need analysable digital scores, which barely exist for full operas as open data — so that stays an honest gap rather than an invented figure.
